# Piper Biancaniello - Real Estate Website

A professional real estate website built for Piper Biancaniello, specializing in buying and selling properties in the Richmond to Williamsburg area.

## Project Structure

- `index.html` - Main HTML structure
- `styles.css` - Styling and layout
- `script.js` - JavaScript functionality
- `piper-photo.jpg` - Profile photo (placeholder)
- `neighborhood.jpg` - Neighborhood image (placeholder)

## Features

- Responsive design (mobile & desktop)
- Smooth navigation scrolling
- Contact form
- Service descriptions (Buying & Selling)
- Neighborhood listings
- Professional color scheme (sage green & cream)

## Setup

1. Add `piper-photo.jpg` and `neighborhood.jpg` to the repo
2. Update contact information in `index.html`
3. Deploy to Vercel, Netlify, or GitHub Pages

## Deployment

You can deploy this site using:
- [Vercel](https://vercel.com)
- [Netlify](https://netlify.com)
- [GitHub Pages](https://pages.github.com)

## Contact Information

Update these fields in `index.html`:
- Phone number
- Email
- Social media handle
- Brokerage information
- License number
